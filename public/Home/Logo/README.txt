AUTONOMOUS MATERIALS GROUP — BRAND PACK (MONO)
================================================

Concept
-------
The mark is a Necker cube (an ambiguous / impossible wireframe) read as a
perovskite unit cell. The single dot at the cube's body-centre is the
perovskite B-site atom. One ink colour throughout — the "mono" system.

Colours
-------
Ink    #1E1C1A   mark, wordmark, tiles
Cream  #F6F2E9   page background, reversed knockout
Stone  #F1ECE0   quiet panels / fills

Type
----
Space Grotesk (SemiBold / 600) — free on Google Fonts:
https://fonts.google.com/specimen/Space+Grotesk
Wordmark tracking: 0.18em, all caps.

Files
-----
svg/   Vector masters — scale to any size.
       symbol-ink / symbol-cream ............ the mark alone (transparent)
       app-icon ............................. ink rounded tile + cream knockout
       lockup-horizontal-* .................. symbol + 3-line wordmark
       lockup-stacked-* ..................... symbol over 2-line wordmark
       All wordmark text is OUTLINED to vector paths — no font needed to
       view, edit, or print these. (Outlines are true Space Grotesk SemiBold.)

png/   Ready-to-place raster, all transparent.
       symbol-ink ........... 16 / 32 / 64 / 128 / 256 / 512 / 1024 px
       symbol-cream ......... 256 / 512 / 1024 px (for dark)
       app-icon ............. 16 / 32 / 180 / 192 / 256 / 512 / 1024 px (favicon/app)
       lockup-horizontal-* .. 1200 / 2400 px wide
       lockup-stacked-* ..... 800 / 1600 px wide

Usage
-----
• Minimum symbol size: 16px (favicon floor).
• Clear space: keep a margin of ⅓ the mark's width on all sides.
• Never recolour, stretch, rotate, or add effects to the mark.
• On photography, place the mark on a solid ink or cream field first.

All SVGs are now pure geometry (no font dependency) — the wordmark text is
outlined to paths. They open and print identically anywhere, including apps
that don't have the font installed.
